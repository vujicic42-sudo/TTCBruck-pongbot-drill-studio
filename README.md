# TTCBruck Pongbot Drill Studio STAGE v1.12

Adds drill-level actions for imported and manually created drills:

- Copy drill / Übung kopieren asks for a new name and creates a deep copy with all current drill and ball configurations.
- Delete drill / Übung löschen asks for confirmation before permanent deletion.
- The three protected basic drills remain protected and do not show these actions.
- All v1.11 behavior remains unchanged.
